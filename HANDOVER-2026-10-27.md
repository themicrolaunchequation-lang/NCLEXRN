## 5. How to publish

### Main site (healthcarecrownacademy.co.uk)
1. Work on the dev branch `claude/dazzling-noether-vpexec` and push it.
2. Then publish:
   ```bash
   cd NCLEXRN
   git checkout live && git pull origin claude/loving-ptolemy-srrq02
   git checkout claude/dazzling-noether-vpexec -- site/<changed files>
   git commit -m "..." && git push origin live:claude/loving-ptolemy-srrq02
   git checkout claude/dazzling-noether-vpexec
   ```
3. Always bump `VERSION` in `site/sw.js` (now `hca-v37`).
4. The CSP allows **no inline scripts** (inline styles are fine). Put JS in `site/assets/js/`.
5. Vercel production deploy takes about 1 minute. Check it with the Vercel MCP `list_deployments` (branch filter).

### Gulf studio
Copy changed shared files (legal pages, `crown-account.js`) into `/home/user/gulf/site/...`, rebuild `apps/gulf` if the app changed, commit, then `git push origin HEAD:claude/gulf-crosswalk`.

### LSS
Make a branch from `origin/main`, commit, push, and give the owner `https://github.com/themicrolaunchequation-lang/lss-healthcare-toolkit/pull/new/<branch>`. A single-branch clone may need `git config --add remote.origin.fetch "+refs/heads/<branch>:refs/remotes/origin/<branch>"` for the stop-hook check.

### Evinca
Commit to `main` with the required author. Vercel builds it automatically.

### Edge functions
Deploy with the Supabase MCP `deploy_edge_function`; keep the source in the repo.

**Problem:** a visitor faces 4 subscriptions × 2 billing periods, a founding price, regional prices, a trial on only one plan, 4 Gulf exams × 3 durations, plus LSS, team plans and Evinca. That is roughly 25 price points on one page.

**Recommended structure (3 cards):**

| Card | What | Price idea |
|---|---|---|
| **Crown Pass** | All Academy apps (MedLex, Carecraft, Lumen with Academy AI) plus Serein free. 7-day trial. | £5.99/month or £39.99/year (founding £29.99) |
| **Crown Pass Gulf** | Everything in Crown Pass plus the Gulf studio for **all four exams** | one-off US$69 for 6 months (or a 3-month US$50 option only) |
| **Lean Six Sigma Green Belt** | professional course with a certificate, 12 months | US$99 one-off |

Then:
- Remove single-app plans from the page (keep them only in the DB for existing subscribers, or drop them before launch, since nobody has paid yet).
- Teams become one line: "Teams of 10+: email us".
- Evinca stays on its own site.
