# Gulf Region Nursing: Arabic scripts for native review

Modern Standard Arabic with a Gulf-friendly tone, addressing viewers in the plural (gender-neutral). Each line mirrors the approved English regional video. Please correct anything that sounds unnatural to a Gulf nurse, especially exam names and the spoken acronyms.

Voices: Gemini text-to-speech, prompted with the region's accent. Gemini has no dedicated country voices, so the reviewer should also judge the accent.

## gsa: المملكة العربية السعودية

| Scene | Speaker | Arabic |
|---|---|---|
| hook | Narrator | اختبار التمريض السعودي، إس إن إل إي: مئتا سؤال، وأربع ساعات. هل أنتم مستعدون؟ |
| rn1 | Nurse | حدّدتُ موعد اختباري. من أين أبدأ؟ |
| reveal | Narrator | تمريض منطقة الخليج، النسخة السعودية. حدّدوا موعد اختباركم، ويقترح عليكم الاستوديو وتيرةً يومية. |
| run | Narrator | شرحٌ لكل سؤال يوضّح لماذا تفوز الإجابة الأكثر أمانًا. اختباراتٌ تجريبية مؤقّتة. أدواتُ قرارٍ سريري مثل بي فاست. ملفاتُ حالاتٍ تخصصية. مسردٌ بالعربية والإنجليزية. وخريطةُ جاهزية تُريكم ما تتدرّبون عليه بعد ذلك. |
| compare | Narrator | ليس مجرد بنك أسئلة. |
| pass | Narrator | باقة الخليج تشمل ميدلكس وكيركرافت ولومن. وتطبيق سيرين مجاني للجميع. |
| cta | Narrator | استعدادٌ للاختبار، مصمَّمٌ لـالمملكة العربية السعودية. ابدأوا مجانًا اليوم، عبر الرابط الظاهر على الشاشة. |
