# Phase 3 — Information architecture

Introduced Today, Learn, Practice, Library, Progress and role-aware Teach,
with Settings and data tools in the avatar menu. Library and term pages have
stable routes, and the previous routes redirect. Removed Start Here strips and
studio promotion banners from page composition. Page help is a labelled control;
short explanations use hover/focus, while research lives in Teach.

Primary implementation files: `index.html`, `src/router/routes.js`, `src/router/index.js`, `src/ui/page.js`, `src/features/modern/controller.js`.

Development checkpoint: `phase-checkpoints/Phase-3.html` in the review ZIP.
Final integrated QA and size measurements are in `validation.json`; the final
release supersedes these intermediate checkpoints.
