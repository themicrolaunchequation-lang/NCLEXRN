# Phase 2 — Design system

Added HCA semantic colour tokens for light, navy dark and high contrast, with
Inter UI typography and Playfair page/term titles. Standardised spacing, controls,
focus rings, mobile targets, motion and reduced-motion behaviour. Reworked the
responsive shell at 720/1024/1280 px, including a 72 px compact navigation rail.
Existing structure is retained for this checkpoint; the following phase removes
old banners and changes navigation. Educational data and branded fonts remain.

Primary implementation files: `src/styles/tokens.css`, `src/styles/components.css`, `src/ui/components/modern.js`.

Development checkpoint: `phase-checkpoints/Phase-2.html` in the review ZIP.
Final integrated QA and size measurements are in `validation.json`; the final
release supersedes these intermediate checkpoints.
