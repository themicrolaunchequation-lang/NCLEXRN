# Clinical content audit and correction record

This is an integration audit with targeted reference checks. It is **not** independent clinical expert sign-off of all 1,350 main-bank questions, 350 dossier cases, 67 raster posters or glossary examples.

## Source limitations

All 1,350 main-bank records explicitly require clinical SME validation and pilot psychometrics. Their text, answer keys and rationales remain unchanged. Software test success does not make these items clinically validated.

The complete v14 package was not available for comparison. The attachment contains later v20–v22 interface layers, retained here. Its separately referenced Interactive Labs dependency was absent.

Scientific-committee and authorship information remains as supplied. Credentials, affiliations and institutional endorsement have not been independently established.

## Every React & Interact tool

All 67 tools retain their specific reasoning job, usage boundary, pearl, trap and handoffs. Each enhanced Decision Lens selects up to three existing linked question IDs, prioritizing first-action/priority, assessment and reassessment/delegation language where available. It shows the patient case, four responses, original keyed answer and explanation, existing distractor misconception labels, follow-up **new application cases**, and how the reasoning may appear in an educational SNLE-style item.

These are reused questions, not new items invented to inflate counts. Follow-ups are labelled as separate cases rather than falsely continuing the same patient. Guided attempts stay separate from main-bank scores.

Existing distractor labels vary in depth. A clinical educator should expand generic labels into full option-specific rationales before describing the bank as comprehensively reviewed.
