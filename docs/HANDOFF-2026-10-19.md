## How to test locally
`node apps/tools/serve-site.mjs 8443` serves `site/` with the live host rewrites + CSP over HTTPS. Launch Chromium (Playwright) with `--no-proxy-server --ignore-certificate-errors --host-resolver-rules="MAP *.healthcarecrownacademy.co.uk 127.0.0.1:8443, MAP healthcarecrownacademy.co.uk 127.0.0.1:8443"` and open `https://<app>.healthcarecrownacademy.co.uk/`. Existing check scripts: `apps/tools/{serein-check,lumen-check,shot,carecraft-*}.mjs`. Test at 1440×900 and 390×844, light and dark, reduced motion; zero console errors; axe-core no serious issues. External services (Supabase, AI) are unreachable in the sandbox — stub with `page.route`. In a cloud session unset proxy vars when running Playwright: `env -u HTTPS_PROXY -u HTTP_PROXY -u https_proxy -u http_proxy ...`.
